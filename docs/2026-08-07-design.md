# Hypervisor Tray — design (2026-08-07)

## Purpose
Tray utility for Windows 11 that shows which hypervisor mode the machine booted in and toggles `hypervisorlaunchtype` for the next boot, making the Docker-vs-VirtualBox-fast trade-off a one-click switch.

Modes:
- **Docker mode** — hypervisor ON (`hypervisorlaunchtype auto`): Docker Desktop/WSL2 work, VirtualBox runs slower under WHP.
- **VirtualBox-fast mode** — hypervisor OFF (`hypervisorlaunchtype off`): VirtualBox native VT-x speed, Docker/WSL2 cannot start.

## Decisions (user-approved)
- Tray runs **unelevated**; each toggle triggers a **UAC prompt** (no scheduled task, no silent elevation).
- After a toggle, a dialog offers **Reboot now / Later**; never auto-reboot without asking.
- Autostart via a Startup-folder shortcut (unelevated), installed by an install script.

## Components
- `HypervisorTray.ps1` — single-file PowerShell 5.1 WinForms tray app. No dependencies.
  - Icon drawn at runtime: blue "D" (Docker mode) / orange "V" (VirtualBox-fast mode); gold dot = next boot differs (reboot pending).
  - Menu: two disabled status lines (current / next boot), "Switch to <other> mode…", "Reboot now…", Exit. Double-click icon = toggle.
  - Current mode read from `Win32_ComputerSystem.HypervisorPresent` (no admin; immutable per boot, so always truthful).
  - Next-boot mode inferred from a state file (`%LOCALAPPDATA%\HypervisorTray\state.json`) written on each successful toggle; a record older than the current boot time is treated as consumed. Known limitation: external `bcdedit` changes aren't detected (reading BCD needs admin).
  - Toggle runs `bcdedit /set hypervisorlaunchtype auto|off` via `Start-Process -Verb RunAs`; UAC decline → balloon, no state change.
  - Single instance via named mutex; PID file for uninstall.
- `Install-HypervisorTray.ps1` — copies the script to `%LOCALAPPDATA%\HypervisorTray`, creates the Startup shortcut (hidden window), starts the tray. `-Uninstall` reverses everything.

## Error handling
- UAC declined / bcdedit nonzero exit → balloon notification, state unchanged.
- Reboot uses `shutdown /r /t 5` (abortable with `shutdown /a`).

## Testing
- `HypervisorTray.ps1 -SelfTest` exercises mode detection, state-file logic, and icon rendering headlessly.
- Syntax-check both scripts under Windows PowerShell 5.1; brief live launch to confirm the tray process stays up.
- Final UAC/toggle/reboot path exercised manually by the user (cannot be automated unelevated).
